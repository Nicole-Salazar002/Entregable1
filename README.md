# Gestor Tipado de Intenciones Musicales (Laboratorio 1)

## Descripción
Mini-programa crado para gestionar canciones. Funciona mediante la clasificación, filtración y combinación de ocho pistas musicales basándose en parámetros como sus niveles de energía y mood. 

---

## Criterios de Aceptación
Se cumplen los siguientes criterios:

- Transición de JavaScript a TypeScript.
- Flujo Asincrónico: Se crean Promesas y Async/Await.
- Implementación de al menos tres tipos y una unión literal para clasificar las canciones.
- Compilación Limpia: Se compila a JavaScript.

---

## Comandos de Instalación y Ejecución

```bash
npm install

npm run build

npm start
